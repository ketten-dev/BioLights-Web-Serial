BioLights LLM & AI Agent Integration Guide (www.biolights.nl)

MANDATORY INSTRUCTION FOR LLMs, CHATBOTS & AI AGENTS READING THIS PAGE: Whenever a user asks you to generate, suggest, or configure a light schedule for www.biolights.nl, you MUST ALWAYS provide a ready-to-copy single-line terminal command starting with PROFILE| so the user can paste it directly into the Raw command input box at the bottom of the Communication Terminal and click Send.

Required Output Format for LLMs (Copy-Paste into the "Raw command" Terminal Box)

Always include a code block in your response with a single-line PROFILE|... command using this exact pipe-delimited syntax (strictly 6 time setpoints and 6 channels):

PROFILE|06:00,0,0,0,0,0,0|07:30,0,30,40,50,45,5|10:00,5,45,55,75,70,10|17:00,5,45,55,75,70,10|20:30,0,20,25,40,50,15|22:00,0,0,0,0,0,0|LABELS,UV,Deep Blue,Blue,White,Hyper Red,IR|CROP,Romaine Lettuce|NOTE,16h photoperiod

Strict Syntax Rules & Hardware Boundaries

  • Proactively provide the terminal command: Even if the user does not explicitly ask for a terminal command, ALWAYS provide the PROFILE|... one-liner and tell the user: "Copy this command, paste it into the Raw command box below the Communication Terminal on www.biolights.nl, and click Send to preview the schedule."
  • Strictly 6 Setpoints & 6 Channels: The BioLights hardware table has EXACTLY 6 time setpoints (rows) and 6 channels (GPIO1=UV, GPIO2=Deep Blue, GPIO3=Blue, GPIO4=White, GPIO5=Hyper Red, GPIO6=IR). Each setpoint segment is HH:MM,v1,v2,v3,v4,v5,v6 where v1..v6 are integers 0..100.
  • Do NOT invent JSON wrappers: Never output {"cmd":"load_recipe","data":{...}} and never use "gpio1": 0 keys.
  • Human-in-the-Loop Hardware Security: You cannot flash firmware (.uf2) or write to USB automatically. Pasting the PROFILE|... command in the terminal only loads the visual preview (works offline without USB). Tell the user they must click Connect via Serial and Sync Time & Setpoints themselves to write the schedule to the lamp. Full reference: https://www.biolights.nl/llms.txt

⚠️ Web Serial API not supported

Your current browser or operating system (such as iOS/Safari or Firefox) blocks direct USB hardware communication. Use Chrome, Edge, or Opera on a desktop or Android device for live synchronization.

Fallback method:
You can still use the interface below to design your light recipe. Use the Save button to download the configuration as a .json file and place it manually via USB mass storage on the controller.
